미래 사회 문제와 과학

분야문제과학 기술의 해결
에너지화석 연료 고갈·기후 변화태양광·풍력, 수소, 핵융합(KSTAR)
환경해양 쓰레기·미세플라스틱생분해성 어망, 쓰레기 자원화, 수중 드론

생활 안전교통사고·재해·감염병AI 위험 예측, 조기 경보, PCR
논증의 4단계 — 서술형 답안 틀
주장(○○ 문제 해결에 과학이 필요) › 근거(○○ 기술이 이렇게 해결) › 사례(실제 적용 예) › 반론 고려(한계와 극복 방안)
시험에 반복되는 함정
  • PCR은 단백질을 검출한다 ✕ — 핵산
  • 면역 진단이 PCR보다 정확하다 ✕ — 빠를 뿐
  • 빅데이터는 양만 많으면 된다 ✕ — 3V(규모·속도·다양성)
  • 공개 데이터라 편향이 없다 ✕ — 편향·신뢰성 검증 필요

입력 — 센서
›
처리 — 마이크로컨트롤러
›
출력 — LED·팬·알림
구성역할 · 예(스마트 공기청정기)

MCUCPU·메모리·입출력을 한 칩에 — 기준치 판단, 팬 속도 결정
출력 장치팬 작동, LED 표시, 스마트폰 알림
  • 센서로 인식하고 통신으로 공유하는 구조가 같으므로, 피지컬 컴퓨팅은 사물 인터넷(IoT)의 기초 기술이다.
5

빅데이터

최빈출
  • 빅데이터 방대한 데이터 자체 + 이를 분석해 새로운 가치를 찾아내는 기술 (공공데이터포털 등에서 공개·공유)
  • 3V Volume 규모 · Velocity 생성·처리 속도 · Variety 형태의 다양성
분야활용 결과
기상 관측실시간 예보, 태풍·홍수 예측, 기후 변화 분석
유전체 분석질환 원인 유전자 발굴, 맞춤형 치료제
신약·의료후보 물질 선별 가속(수년 → 수일), AI 영상 판독
빅데이터 + 인공지능
AI가 방대한 데이터를 학습 → 패턴·규칙을 스스로 파악 → 새 데이터가 들어오면 예측·판단·최적화

빅데이터의 장점과 문제점

구분내용
장점직접 수집 없이 공개 데이터 활용 / 숨은 패턴·인과관계 발견 / 실시간 처리로 빠른 의사 결정
개인 정보수집·분석 과정에서 민감 정보 유출 → 동의 절차·익명화로 대응
데이터 편향편중된 데이터로 학습하면 차별적 결론 → 균형 있는 데이터셋, 편향 감사
  • 신뢰성 품질이 낮으면 결과도 무의미 / 데이터 리터러시 출처·편향·분석 방법을 비판적으로 평가하는 소양

Ⅲ. 과학과 미래 사회 — 핵심정리 ②

인공지능 로봇 · 사물 인터넷 · 과학 관련 사회적 쟁점(SSI) · 과학 윤리
7

사회적 쟁점의 합의 4단계

순서 암기
  • SSI는 과학 기술이 정치·경제·환경·윤리와 얽혀 가치와 이해관계에 따라 의견이 갈리는 쟁점이다. 과학적 사실만으로는 해결되지 않는다.
8

인공지능 로봇

  • 초기 로봇 정해진 프로그램대로만 작동 → 예상 밖 상황에 대응 못함 / 인공지능 로봇 센서로 인식하고 스스로 학습·판단해 변화에 대응
로봇인공지능이 하는 일
청소·서빙 로봇공간 지도 생성, 장애물 회피, 최적 경로 계산
대화형·반려 로봇자연어 처리, 감정 인식, 사용자 패턴 학습
의료·산업 로봇영상 분석, 정밀 모터 제어, 불량품 감지
구분내용
유용성위험 작업에서 인간 보호(재난·방사선) / 정밀 수술로 회복 빠름 / 인력 부족 분야 지원
한계일자리 대체 / 책임 소재 불분명(사고 시 제조사·사용자?) / 오작동·해킹 위험
  • AI가 대체하기 어려운 영역은 공감 · 창의성 · 윤리적 판단이 핵심인 일이다.
9

사물 인터넷(IoT)

  • 사물에 센서와 통신 기술을 넣어 인터넷에 연결하고, 사물끼리·사람과 정보를 교환하며 사람이 개입하지 않아도 스스로 인식·제어하는 기술
사례작동 방식 · 효과
스마트홈센서가 사람 감지 → 조명·냉난방 자동 제어 → 에너지 절약
스마트팜온습도·일조량·토양 센서 → 관개·환기 자동 → 생산성 향상
자율주행차카메라·레이더·라이다 → AI가 속력·방향 조절
스마트시티가로등·주차·교통 신호 통합 관리 → 혼잡 완화
  • 유용성 자동화로 편의성·에너지 효율 향상 / 한계 해킹 시 카메라 감시·차량 원격 제어 위험, 생활 데이터 무단 활용
  • 대응 제조사는 보안 설계 강화, 사용자는 기본 비밀번호 변경·최신 업데이트 유지
시험에 반복되는 함정
  • SSI는 과학적 사실만으로 결론이 난다 ✕ — 가치 판단이 개입
  • AI 로봇은 모든 직업을 대체한다 ✕ — 공감·창의·윤리는 어렵다
  • IoT는 장점만 있다 ✕ — 해킹·개인정보 위험
10

사회적 쟁점 사례

서술형 대비
자율주행차근거
찬성노인·장애인의 이동권 보장 / 부주의로 인한 사고 감소 / 연료 효율 향상
반대사고 시 탑승자와 보행자 중 누구를 보호할지 윤리 문제 / 해킹 / 책임 소재 불명확
극지방 개발근거
찬성북극항로로 이동 거리 단축 → 연료·CO₂ 감소 / 자원 개발
반대빙하 훼손 → 해수면 상승 / 극지 생태계 파괴 / 온난화 가속의 악순환
  • 좋은 논증의 조건 검증된 과학적 사실에 근거 · 경제 외에 환경·안전·형평성 등 다양한 가치 고려 · 상대 입장 존중 · 지속 가능성의 장기적 시각
11

과학 윤리

  • 과학 기술의 개발·활용은 개인의 삶과 사회·생태계에 큰 영향을 준다 → 올바르게 이용하기 위한 규범이 과학 윤리
유전자 편집 아기 사건 (2018)
유전자 가위(CRISPR)로 배아의 유전자를 편집해 쌍둥이를 탄생시킨 사건. ① 편집된 유전자가 다음 세대로 영구 전달 ② 본인 동의 없이 유전자 변경 ③ 안전성 검증 부족 → 학계의 강한 비난과 실형 선고
분야윤리 문제 → 지켜야 할 원칙
생명공학생명 존엄성 침해·맞춤형 아기 → 생명 가치 존중, 충분한 안전성 검증
정보통신동의 없는 데이터 수집·허위 정보 → 동의 절차, 익명화, 진위 검증
인공지능책임 소재·데이터 편향 → 투명성, 편향 없는 학습, 인간이 중단 가능
사람이 중심이 되는 AI 윤리 기준 — 3대 원칙
① 인간 존엄성 ② 사회의 공공선 ③ 기술의 합목적성 — 핵심 요건에는 인권 보장·프라이버시·다양성 존중·책임성·안전성·투명성이 포함된다.
