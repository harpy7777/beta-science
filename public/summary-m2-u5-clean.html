Ⅴ.식물과 에너지— 중2 과학핵심정리
〈 광합성 〉
▪광합성 = 식물이 빛에너지를 이용해 스스로 양분을 만드는 과정
▪장소 = 식물세포의 엽록체 · 그 안의 초록색 색소 엽록소가 빛을 흡수
이산화 탄소 + 물 → 포도당 + 산소
필요한 물질들어오는 길
빛에너지엽록소가 흡수
이산화 탄소잎의 기공으로
물뿌리 흡수 → 물관으로
▪산물  포도당 → 곧 녹말로 바뀌어 저장 · 산소는 기공으로 배출
→확인 실험  에탄올로 탈색 후 아이오딘 용액 → 청람색이면 녹말 생성
〈 광합성에 영향을 주는 환경요인 〉
환경요인광합성량의 변화
빛의 세기셀수록 증가 → 일정 이상이면 일정
이산화 탄소 농도높을수록 증가 → 일정 이상이면 일정
온도높을수록 증가 → 일정 이상이면 급격히 감소
∴엽록체 수가 한정되어 있어 무한정 증가하지 않는다
＊함정 주의
온도도 높을수록 계속 증가한다 → ✗  온도만 감소로 꺾인다 중요
빛·이산화 탄소는 일정해지고, 온도는 떨어진다
〈 식물의 호흡 〉
▪호흡 = 세포에서 양분을 분해해 에너지를 얻는 과정
포도당 + 산소 → 이산화 탄소 + 물
→장소는 마이토콘드리아 · 이 과정에서 에너지가 방출된다
〈 광합성과 호흡 비교 〉
구분광합성호흡
시기주로 낮(빛이 있을 때)항상(낮·밤 모두)
장소엽록체마이토콘드리아
필요 물질이산화 탄소 · 물포도당 · 산소
생성 물질포도당 · 산소이산화 탄소 · 물
양분합성분해
에너지빛에너지 흡수에너지 방출
▪낮  광합성 > 호흡 → 이산화 탄소 흡수 · 산소 방출
▪밤  호흡만 → 산소 흡수 · 이산화 탄소 방출
＊함정 주의
식물은 낮에만 호흡한다 / 밤에만 호흡한다 → ✗
호흡은 낮에도 밤에도 항상 일어난다 중요
〈 광합성산물의 저장과 이용 〉
포도당›녹말(엽록체 저장)›설탕›체관으로 이동
▪녹말은 주로 밤에 설탕으로 바뀌어 이동한다
∴물은 물관, 광합성산물은 체관으로 이동
▪이용  호흡의 에너지원 · 몸을 구성해 성장·개화 · 동물의 먹이
식물저장 부위저장 형태
포도열매포도당
사탕수수줄기설탕
고구마 · 감자뿌리 · 줄기녹말
콩씨단백질
깨 · 땅콩씨지방
＊함정 주의
광합성산물은 모두 녹말로 저장된다 → ✗
식물·부위에 따라 포도당 · 설탕 · 단백질 · 지방으로도 저장된다
〈 자주 틀리는 5가지 〉
① 호흡을 밤에만 한다고 씀 → 항상 일어남
② 온도가 높을수록 광합성량이 계속 증가한다고 씀 → 일정 이상이면 감소
③ 광합성산물이 물관으로 이동한다고 씀 → 체관
④ 광합성 장소를 마이토콘드리아라고 씀 → 엽록체
⑤ 저장 형태를 모두 녹말이라 씀 → 단백질 · 지방도 있음
