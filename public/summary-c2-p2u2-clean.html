Ⅱ.산화·환원 반응— 고2 화학 반응의 세계핵심정리
〈 산화·환원과 전자의 이동 〉
▪산화 — 전자를 잃음 → 산화수 증가  ·  환원 — 전자를 얻음 → 산화수 감소
∴산화와 환원은 항상 동시에 일어난다 — 잃는 쪽이 있으면 얻는 쪽이 반드시 있다
2Mg(s) + O2(g) → 2MgO(s)  Mg는 전자 2개를 잃어 산화, O2는 전자를 얻어 환원
→이온 결합 물질에서는 전자의 이동이 눈에 보이게 드러난다
〈 산화수 결정 규칙 일곱 가지 〉
▪전기음성도가 큰 원자가 공유 전자쌍을 모두 가진다고 가정했을 때 각 원자의 전하
→덕분에 공유 결합 물질에서도 산화·환원을 설명할 수 있다
규칙내용예
1원소(단체)를 이루는 원자 = 0H2 · O2 · Cu · Zn → 0
2단원자 이온 = 이온의 전하Na+ +1 · Mg2+ +2 · Cl− −1
3F는 항상 −1HF → F = −1
4H는 +1  금속 수소화물은 −1HCl → +1  /  NaH → −1
5O는 −2  과산화물은 −1H2O → −2  /  H2O2 → −1
6화합물의 산화수 합 = 0CO2 (+4) + (−2)×2 = 0
7다원자 이온의 합 = 이온의 전하SO42− (+6) + (−2)×4 = −2
구하는 법  아는 원자부터 넣고 합이 0(또는 이온 전하)이 되도록 미지수를 푼다
HNO3의 N  (+1) + N + (−2)×3 = 0 → N = +5  |  CH4의 C  C + (+1)×4 = 0 → C = −4
〈 산화제와 환원제 〉
구분자기 자신상대에게포함한 원자의 산화수
산화제환원된다산화시킨다감소하는 원자를 가짐
환원제산화된다환원시킨다증가하는 원자를 가짐
→헷갈리면 "산화제는 자기가 환원된다"만 외우면 나머지는 따라온다
Fe2O3 + 3CO → 2Fe + 3CO2  Fe +3 → 0 산화제  |  C +2 → +4 환원제
같은 물질(SO2 등)도 반응에 따라 산화제·환원제 양쪽으로 작용할 수 있다
〈 반쪽 반응식 완성 4단계 〉
① 산화 반응식과 환원 반응식으로 분리
② 각 식에서 반응 전후 원자 수 맞추기
③ 잃거나 얻은 전자 수 표기
④ 잃은 전자 수 = 얻은 전자 수가 되도록 계수를 맞추고 두 식을 더한다
KI + Cl2 → KCl + I2
산화  2I− → I2 + 2e−  (I −1 → 0, 증가)
환원  Cl2 + 2e− → 2Cl−  (Cl 0 → −1, 감소)
전자 수가 같으므로 그대로 더한다 → 2KI + Cl2 → 2KCl + I2
＊함정 주의
산화제는 자기가 산화된다 → ✗  산화제는 자기가 환원되면서 남을 산화시킨다 중요
O의 산화수는 항상 −2다 → ✗  과산화물(H2O2)에서는 −1
H의 산화수는 항상 +1이다 → ✗  금속 수소화물(NaH)에서는 −1
〈 화학 전지의 원리 〉
▪산화·환원 반응으로 화학 에너지 → 전기 에너지를 만드는 장치
구성반응전자
(−)극  산화 전극산화 — 전자를 잃음전자가 나간다
(+)극  환원 전극환원 — 전자를 얻음전자가 들어온다
전해질이온이 이동해 회로를 완성한다
→전자는 도선을 따라 (−)극 → (+)극으로 흐른다
〈 볼타 전지와 다니엘 전지 〉
구분볼타 전지다니엘 전지
구성Zn판 + Cu판 + H2SO4(aq)Zn|ZnSO4 || CuSO4|Cu
(−)극Zn → Zn2+ + 2e−  산화  아연판 질량 감소
(+)극2H+ + 2e− → H2  환원Cu2+ + 2e− → Cu  구리판 질량 증가
문제점분극 현상염다리로 해결
▪분극 — (+)극에서 생긴 H2 기체가 전극 표면을 덮어 환원을 방해 → 전압이 떨어진다
다니엘 전지 전체 반응  Zn(s) + Cu2+(aq) → Zn2+(aq) + Cu(s)
▪염다리 — 두 수용액을 잇고 이온을 이동시켜 전하 균형을 유지한다
→음이온은 (−)극 쪽으로, 양이온은 (+)극 쪽으로 이동
〈 일차 전지와 이차 전지 〉
구분충전종류특징
일차 전지불가 (1회용)망가니즈·알칼리 건전지, 단추형구조 간단, 휴대 편리, 수명 한정
이차 전지가능납축전지, 리튬 이온, 니켈·카드뮴반복 사용, 경제적
전지구성특징
망가니즈 건전지NH4Cl 반죽 + MnO2 + 흑연아연통이 부식되는 단점
알칼리 건전지KOH (염기성)아연과 반응 없음 → 수명이 더 길다
납축전지Pb + PbO2 + H2SO4직렬로 고전압, 무겁다 — 자동차용
리튬 이온 전지Li+가 양극재 ↔ 음극재 이동가볍고 에너지 밀도 높다 — 스마트폰·전기차
공통 구조  ① 산화·환원 전극 분리  ② 사이에 전해질  ③ 전자는 도선으로 (−) → (+)
〈 표준 환원 전위 E° 〉
▪반쪽 전지의 산화·환원 경향을 비교하는 척도
→E°가 크면 환원이 잘 됨 → (+)극  /  E°가 작으면 산화가 잘 됨 → (−)극
▪표준 수소 전극 — 25℃, H+ 1 M, H2 1 atm, 백금 전극  E° = 0.00 V 기준
반쪽 반응E° (V)반쪽 반응E° (V)
F2 + 2e− → 2F−+2.87Pb2+ + 2e− → Pb−0.13
Cl2 + 2e− → 2Cl−+1.36Ni2+ + 2e− → Ni−0.26
O2 + 4H+ + 4e− → 2H2O+1.23Fe2+ + 2e− → Fe−0.45
Ag+ + e− → Ag+0.80Zn2+ + 2e− → Zn−0.76
Cu2+ + 2e− → Cu+0.34Al3+ + 3e− → Al−1.68
2H+ + 2e− → H20.00Li+ + e− → Li−3.04
위로 갈수록 환원이 잘 되고, 아래로 갈수록 산화가 잘 된다
〈 표준 전지 전위와 전지 표기법 〉
E°전지 = E°환원 전극 − E°산화 전극
환원 전극 = (+)극  ·  산화 전극 = (−)극
다니엘 전지  0.34 − (−0.76) = 1.10 V
→전압을 높이려면 두 반쪽 전지의 E° 차이를 크게 잡으면 된다
전지 표기 규칙
왼쪽 = 산화 전극  ·  오른쪽 = 환원 전극
| 는 서로 다른 상의 경계  ·  || 는 염다리
다니엘 전지  Zn(s) | Zn2+(aq) || Cu2+(aq) | Cu(s)
＊함정 주의
E°전지 = 환원 E° + 산화 E° → ✗  더하기가 아니라 빼기다 중요
E°가 작을수록 좋은 (+)극이다 → ✗  E°가 클수록 환원이 잘 돼 (+)극이 된다
전지 표기에서 왼쪽이 (+)극이다 → ✗  왼쪽은 산화 전극 = (−)극
〈 전기 분해 〉
▪전기 에너지를 가해 비자발적인 산화·환원 반응을 일으키는 것
구분화학 전지전기 분해
에너지화학 → 전기전기 → 화학
반응자발적비자발적
(+)극환원 전극산화 전극
(−)극산화 전극환원 전극
예다니엘 전지 · 건전지NaCl 전기 분해 · 도금
∴두 장치는 극의 이름과 반응이 정반대다 — 여기서 가장 많이 틀린다
〈 용융액 · 수용액의 전기 분해 〉
▪NaCl 용융액  이온만 있으므로 이온이 그대로 반응한다
(+)극  2Cl− → Cl2 + 2e−  |  (−)극  2Na+ + 2e− → 2Na
▪수용액  전해질의 이온과 H2O가 경쟁해서 더 쉽게 반응하는 쪽이 이긴다
CuSO4(aq)  (+)극 2H2O → O2 + 4H+ + 4e−  (SO42−보다 물이 쉽게 산화)
              (−)극 2Cu2+ + 4e− → 2Cu  (물보다 Cu2+가 쉽게 환원)
▪물의 전기 분해  순수한 물은 전류가 안 흐르므로 전해질을 조금 넣는다
(+)극  2H2O → O2 + 4H+ + 4e−  |  (−)극  4H2O + 4e− → 2H2 + 4OH−
→H2와 O2가 2 : 1 부피비로 발생한다
〈 도금과 구리 정제 〉
구분(+)극  산화(−)극  환원
도금도금할 금속판 — 이온을 공급도금될 물체 — 금속이 석출
구리 정제불순물 섞인 구리순수한 구리 (CuSO4 전해질)
→물체를 (−)극에 다는 이유  (−)극이 환원 전극이라 금속 이온이 전자를 얻어 표면에 붙기 때문
은도금  (+)극 Ag → Ag+ + e−  |  (−)극 Ag+ + e− → Ag
구리 정제에서 불순물이 갈라지는 원리
(+)극에서는 불순물과 Cu가 모두 산화되지만, (−)극에서는 E°가 큰 Cu2+만 환원된다
Zn · Fe · Ni  Cu보다 E°가 작다 → 이온 상태로 남아 제거된다
Ag · Au · Pt  Cu보다 E°가 커서 산화되지 않는다 → (+)극 아래 침전된다
〈 생명 현상 속 산화·환원 〉
반응산화되는 것 (환원제)환원되는 것 (산화제)
세포호흡포도당 — C의 산화수 증가O2 — O가 0 → −2
광합성H2O — O의 산화수 증가CO2 — C의 산화수 감소
질소 고정H2N2 — N이 0 → −3
C6H12O6 + 6O2 → 6CO2 + 6H2O  ·  N2 + 3H2 → 2NH3
∴광합성은 세포호흡의 역반응이다
▪바이타민 C — 전자를 잘 내주어 쉽게 산화됨 → 활성 산소를 대신 제거하는 환원제
질소 고정  뿌리혹세균이 자연적으로, 하버-보쉬법으로 산업적으로 이루어진다
〈 연료 전지 〉
▪외부에서 연료를 계속 공급받아 끊이지 않고 작동하는 전지
(−)극  2H2 → 4H+ + 4e−  산화  |  (+)극  O2 + 4H+ + 4e− → 2H2O  환원
전체  2H2(g) + O2(g) → 2H2O(l)
장점단점
부산물이 물뿐 — 친환경수소 생산에 에너지가 많이 든다
에너지 효율이 높다수소 저장·운반 비용이 크다
지속적으로 작동한다폭발 위험성이 있다
〈 리튬 이온 전지와 미래 전지 〉
리튬 이온 전지 장점리튬 이온 전지 단점
가볍고 에너지 용량이 크다열에 약해 화재 위험
수명이 길고 충전된다리튬·코발트 채굴로 환경 오염
스마트폰·전기차·ESS에 쓰인다폐전지 처리 문제
미래 전지의 조건  친환경 소재 · 안전하고 경제적 · 폐전지 재활용 가능
연구 방향  나트륨 이온 전지 · 전고체 전지(안전성 향상) · 폐수에서 암모니아 추출
〈 자주 틀리는 5가지 〉
① 산화제가 산화된다고 씀 → 산화제는 자기가 환원된다
② E°전지를 더해서 구함 → 환원 E° − 산화 E°, 빼기다
③ 전기 분해의 (+)극을 환원 전극이라 씀 → 전기 분해는 (+)극이 산화 전극
④ H2O2의 O를 −2라고 씀 → 과산화물이라 −1
⑤ 다니엘 전지에서 아연판이 무거워진다고 씀 → 아연이 녹아 나가 가벼워진다
