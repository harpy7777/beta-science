Ⅰ. 변화와 다양성 — ② 화학 변화 핵심정리
〈 산화와 환원은 항상 동시에 〉 · 핵심 원리
2CuO + C → 2Cu + CO2
CuO 산소를 잃음 → 환원  |  C 산소를 얻음 → 산화
∴ 한쪽이 산화되면 반드시 다른 쪽은 환원된다
〈 산화·환원의 두 가지 정의 〉 · 최빈출
구분산소의 이동전자의 이동
산화산소를 얻음전자(e-)를 잃음
환원산소를 잃음전자(e-)를 얻음
산화 = 산소 얻고 전자 잃고 / 환원 = 산소 잃고 전자 얻고
✓ 전자 이동의 예
Cu + 2Ag+ → Cu2+ + 2Ag
Cu는 전자를 잃어 산화 · Ag+은 전자를 얻어 환원 · 전자는 Cu → Ag+ 방향으로 이동
〈 철의 제련과 생활 속 산화·환원 〉
✓ 철의 제련 (용광로)
① 2C + O2 → 2CO (탄소가 산화)
② Fe2O3 + 3CO → 2Fe + 3CO2 — CO는 산화 · Fe2O3는 환원되어 순수한 철을 얻는다
생활 속 사례내용
철의 부식4Fe + 3O2 → 2Fe2O3 — 철이 산소를 얻어 산화
연소CH4 + 2O2 → CO2 + 2H2O — 연료의 산화
광합성CO2가 환원되어 포도당 생성
호흡포도당이 산화되어 에너지 방출
〈 산과 염기 · 중화 반응 〉
구분정의 (아레니우스)예
산물에 녹아 H+을 내놓는 물질HCl → H+ + Cl- / H2SO4
염기물에 녹아 OH-을 내놓는 물질NaOH → Na+ + OH- / Ca(OH)2
✓ 중화 반응의 핵심
H+ + OH- → H2O   (예: HCl + NaOH → NaCl + H2O)
남은 이온으로 액성 판단 — H+ 남으면 산성 · OH- 남으면 염기성 · 모두 반응하면 중성
▪ 중화열은 실제로 반응한 H+·OH-의 수에 비례한다
→ 완전히 중화되는 지점에서 온도가 가장 높다
〈 생활 속 중화 반응 〉
상황중화 방법
생선 비린내 (염기성)레몬즙·식초 등 산성으로 중화
충치 예방세균이 만든 산 → 염기성 치약으로 중화
위산 과다염기성 제산제 복용
산성화된 토양석회 가루 살포
벌레 물린 곳산성인 벌레의 독 → 암모니아수
〈 물질 변화에서 에너지의 출입 〉
구분열에너지주변 온도
발열 반응반응계 → 주변으로 방출 (반응물 에너지 > 생성물)상승
흡열 반응주변 → 반응계로 흡수 (반응물 에너지 < 생성물)하강
발열 예 연소 · 손난로(철의 산화) · 산화칼슘 + 물 · 중화 반응
흡열 예 냉찜질(질산 암모늄 용해) · 광합성 · 열분해
⚠ 시험에 반복되는 함정
산화와 환원이 따로 일어난다 × — 항상 동시
산화 = 전자를 얻는 것 × — 전자를 잃는 것
중화 반응에서 물 대신 다른 물질이 먼저 × — H+ + OH- → H2O
흡열 반응이면 주변 온도가 오른다 × — 내려간다
