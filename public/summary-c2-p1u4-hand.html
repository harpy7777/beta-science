Ⅳ.반응 속도— 고2 물질과 에너지핵심정리
〈 반응 속도의 정의 〉
▪일정 시간 동안의 농도 변화량으로 나타낸다  [mol/(L·s)]
v = − Δ[반응물] / Δt = + Δ[생성물] / Δt
→반응물은 농도가 줄어 음수, 생성물은 늘어 양수 — 부호를 붙여 양수로 맞춘다
▪계수가 다르면 변화량도 다르므로 계수로 나누어 하나의 값으로 통일한다
2A(g) + B(g) → C(g)  →  v = −½(Δ[A]/Δt) = −(Δ[B]/Δt) = +(Δ[C]/Δt)
〈 반응 속도 측정 방법 〉
반응 종류측정 방법예
기체 발생기체의 부피·압력 또는 반응물 질량 감소CaCO3 + HCl → CO2
앙금 생성×표가 안 보일 때까지 걸린 시간Na2S2O3 + HCl → S
색 변화색이 변할 때까지 걸린 시간KIO3 + NaHSO3 → I2
〈 평균 · 순간 · 초기 반응 속도 〉
종류정의그래프에서
평균 반응 속도어떤 구간 동안의 속도두 점을 잇는 직선의 기울기
순간 반응 속도특정 순간의 속도그 점에서 접선의 기울기
초기 반응 속도t = 0 에서의 순간 속도t = 0 에서 접선의 기울기
▪시간이 지날수록 속도가 느려지는 이유
반응물 농도 감소›충돌 횟수 감소›반응 속도 감소
〈 반응 속도식과 반응 차수 〉
v = k[A]m[B]n
용어의미특징
반응 속도 상수 k반응 고유의 비례 상수온도로만 변함 · 농도·압력과 무관
반응 차수 m, n농도가 속도에 미치는 지수반응식 계수와 무관 · 실험으로만 결정
전체 반응 차수m + n0차 · 1차 · 2차 · 3차
전체 차수0차1차2차3차
k의 단위M/s1/s1/(M·s)1/(M2·s)
▪차수 구하는 순서
① 한 물질의 농도만 바꾼 두 실험을 고른다
② 농도가 a배일 때 속도가 b배면  am = b  로 m을 구한다
③ 실험값 하나를 대입해 k를 구한다
→농도를 2배로 했을 때  속도 2배 → 1차  ·  속도 4배 → 2차  ·  속도 그대로 → 0차
＊함정 주의
반응 차수는 화학식 계수와 같다 → ✗  실험으로만 정해지고 계수와 무관 중요
농도를 높이면 k가 커진다 → ✗  k는 온도로만 변한다
속도가 빠르면 차수가 높다 → ✗  차수는 농도에 얼마나 민감한가일 뿐
〈 일차 반응 〉
▪반응 속도가 반응물 농도에 비례하는 반응  v = k[A]
→농도–속도 그래프가 원점을 지나는 직선 (기울기 = k)
예  방사성 동위 원소 붕괴 · 2N2O5 → 4NO2 + O2
[N2O5] 0.9 M → v = 5.4 × 10−4  |  0.45 M → v = 2.7 × 10−4  농도 절반 → 속도 절반
〈 반감기 〉
▪반응물 농도가 절반으로 줄어드는 데 걸리는 시간
일차 반응만의 특징
농도가 절반이 되면 속도도 절반이 되므로 다음 반감기도 같은 시간이 걸린다
→ 일차 반응의 반감기는 초기 농도와 무관하게 항상 일정
이차 반응 이상에서는 반감기가 농도에 따라 달라진다
[A]n = [A]0 × (½)n
[A]0 → ½ → ¼ → ⅛ …  n은 반감기를 지난 횟수
→반감기가 일정하다는 것이 보이면 그 반응은 일차 반응이라고 판단한다
〈 반감기의 활용 〉
활용내용
14C 연대 측정반감기 5730년 · 약 5만 년 이내 유물·화석
의료용 동위 원소131I 갑상샘 치료 · 99Tc 진단 — 적절한 반감기를 골라 쓴다
약물 투여 간격혈액 속 농도를 반감기로 계산해 복용 횟수 결정
수돗물 소독염소 분해가 일차 반응 → 투입량·횟수 조절
원리  살아 있을 땐 14C를 계속 보충 → 죽으면 감소 시작 → 지금의 14C / 12C 비율로 시기를 계산
〈 유효 충돌 〉
▪충돌한다고 다 반응하지 않는다 — 실제로 반응이 일어나는 충돌이 유효 충돌
충돌방향에너지반응
비유효 (가)적합하지 않음—✗
비유효 (나)적합함Ea 미만✗
유효 (다)적합함Ea 이상○
∴조건 두 개가 동시에 만족되어야 한다 — 방향 + 에너지
〈 활성화 에너지 〉
▪Ea — 반응이 일어나기 위한 최소한의 에너지 (에너지 장벽)
→Ea 클수록 반응 어렵고 느리다  /  작을수록 쉽고 빠르다
▪활성화물 — 결합이 끊어지기 직전의 불안정한 상태 (전이 상태)
반응물›활성화물›생성물
에너지 그래프에서 활성화물은 곡선의 가장 높은 점
구분발열 (ΔH < 0)흡열 (ΔH > 0)
역반응 Ea′Ea + |ΔH|  역이 더 크다Ea − |ΔH|  역이 더 작다
ΔH 구하기ΔH = Ea(정) − Ea(역)
∴ΔH는 반응물–생성물의 차, Ea는 반응물–활성화물의 차 — 서로 무관
＊함정 주의
Ea가 크면 발열 반응이다 → ✗  Ea와 ΔH는 아무 관계 없다 중요
충돌하기만 하면 반응한다 → ✗  방향과 에너지를 모두 만족해야 한다
촉매를 쓰면 ΔH도 작아진다 → ✗  Ea만 변하고 ΔH는 그대로
〈 농도 · 표면적과 반응 속도 〉
농도 ↑›단위 부피당 입자 수 ↑›충돌수 ↑›유효 충돌 ↑›속도 ↑
상태농도를 높이는 방법효과
기체압력 ↑ → 부피 ↓단위 부피당 분자 수 증가
고체입자를 잘게 → 표면적 ↑반응은 표면에서만 일어나므로 접촉 면적이 중요
사례  풀무로 불 피우기 · 알약을 가루약으로 · 재료를 잘게 썰기 · 로켓 연료
〈 온도와 반응 속도 〉
▪충돌수 증가는 약 2%뿐 — 이것만으로는 설명이 안 된다
▪진짜 이유는 Ea 이상의 에너지를 가진 분자 수가 급격히 증가하기 때문
운동 에너지 분포 곡선  온도 ↑ → 곡선이 넓고 낮게 퍼짐 → Ea 오른쪽 넓이가 크게 증가
→온도가 10℃ 오르면 반응 속도는 대략 2배
▪속도식에서는 농도가 아니라 k가 커진다 (k는 온도로만 변하므로)
사례  냉장고 보관 · 기름으로 조리(끓는점이 높아 고온) · 비닐하우스 · 택배 아이스팩
〈 촉매 〉
▪소모되지 않으면서 반응 속도를 바꾸는 물질 — 반응 경로를 바꿔 Ea를 변화시킨다
∴촉매를 써도 ΔH는 변하지 않는다

▪효소 — 단백질로 된 생체 촉매

〈 자주 틀리는 5가지 〉
① 반응 차수를 반응식 계수로 씀 → 실험으로만 결정
② 농도를 높이면 k가 커진다고 씀 → k는 온도로만 변함
③ 반감기가 항상 일정하다고 씀 → 일차 반응일 때만 일정
④ 촉매가 ΔH를 바꾼다고 씀 → Ea만 바뀜
⑤ Ea가 크면 흡열이라고 씀 → Ea와 ΔH는 무관
