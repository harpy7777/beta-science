Ⅰ.물질의 특성— 중2 과학핵심정리
〈 물질의 특성 〉
▪물질의 특성 = 다른 물질과 구별되는 그 물질만의 고유한 성질
∴물질의 양에 관계없이 항상 일정하다
▪예  밀도 · 녹는점 · 끓는점 · 용해도 · 색 · 냄새 · 맛
구분순물질혼합물
정의한 가지 물질두 가지 이상이 섞임
밀도일정성분비에 따라 변함
녹는점·끓는점일정일정하지 않음
예물 · 구리 · 산소공기 · 바닷물 · 간장
＊함정 주의
질량과 부피도 물질의 특성이다 → ✗  양에 따라 변하므로 특성이 아님 중요
소금물은 끓는 동안 온도가 계속 오른다 / 순물질인 물은 100 ℃로 일정
〈 밀도 〉
▪밀도 = 단위 부피당 질량 · 온도와 압력이 같으면 물질마다 고유
밀도(g/cm³) = 질량(g) ÷ 부피(cm³)
▪물체 밀도 < 액체 밀도 → 뜬다  /  > → 가라앉는다
물질밀도물질밀도
에탄올0.79철7.87
얼음0.92구리8.96
물1.00금19.3
＊함정 주의
같은 물질이면 크기가 달라도 밀도는 같다
얼음이 물보다 밀도가 크다 → ✗  얼음 0.92 < 물 1.00 이라 뜬다
〈 녹는점과 끓는점 〉
▪녹는점 = 고체 → 액체  /  끓는점 = 액체 → 기체  /  어는점 = 액체 → 고체
∴어는점 = 녹는점 (같은 온도)
▪물질마다 다르고, 양에 관계없이 일정 → 물질의 특성

＊함정 주의
혼합물은 끓는점이 일정하지 않다
소금물 — 물보다 높은 온도에서 끓기 시작하고 끓는 동안 온도가 계속 상승
〈 용해도 〉
▪용해도 = 어떤 온도에서 용매 100 g에 최대로 녹는 용질의 질량(g)
▪고체  온도 ↑ → 용해도 ↑  (예외 : 수산화 칼슘)
▪기체  온도 ↑ → 용해도 ↓  /  압력 ↑ → 용해도 ↑
→탄산음료 뚜껑을 열면 거품 = 압력 감소 · 여름에 물고기가 힘들어함 = 수온 상승
▪석출 = 녹아 있던 용질이 고체로 분리되는 현상 (냉각 · 용매 증발)
＊함정 주의
기체도 온도가 높을수록 잘 녹는다 → ✗  기체는 고체와 반대 중요
〈 혼합물의 분리 〉
이용하는 특성방법예
밀도 차분별 깔때기 · 원심 분리물과 식용유 · 혈액 · 기름 유출
끓는점 차증류물과 에탄올 · 원유 증류탑 · 담수화
용해도 차재결정질산 칼륨 · 꽃소금 · 아스피린
▪분별 깔때기  두 층으로 나뉘면 아래층(밀도 큰 물)을 먼저 받아낸다
▪증류  끓는점이 낮은 물질이 먼저 끓어 나옴 (에탄올 78 ℃ < 물 100 ℃)
▪재결정  온도를 낮추면 용해도 차가 큰 질산 칼륨이 먼저 석출
→황산 구리(Ⅱ)는 용해도 변화가 작아 용액에 남는다
＊함정 주의
분별 깔때기는 위층을 먼저 빼낸다 → ✗  반드시 아래층 먼저
〈 자주 틀리는 5가지 〉
① 질량·부피를 물질의 특성이라 씀 → 양에 따라 변해 특성 아님
② 얼음 밀도를 물보다 크다고 씀 → 0.92 < 1.00
③ 기체 용해도를 고체와 같게 씀 → 온도 ↑ 면 작아진다
④ 분별 깔때기에서 위층부터 빼냄 → 아래층 먼저
⑤ 증류에서 끓는점 높은 것이 먼저 나온다고 씀 → 낮은 것 먼저
