Ⅲ.화학 변화의 자발성— 고2 물질과 에너지핵심정리
〈 엔탈피와 반응 엔탈피 〉
▪엔탈피 H — 물질이 일정 온도·압력에서 갖는 고유 에너지  직접 측정 불가
▪반응 엔탈피 ΔH — 일정 압력에서 반응이 일어날 때의 엔탈피 변화
ΔH = H생성물 − H반응물
구분엔탈피ΔH 부호열 이동주위 온도
발열 반응반응물 > 생성물ΔH < 0계 → 주위 방출상승 ↑
흡열 반응반응물 < 생성물ΔH > 0주위 → 계 흡수하강 ↓
발열 예  연소 · 손난로(철의 산화) · 산화 칼슘 + 물 · 중화 반응
흡열 예  광합성 · 질산 암모늄 용해 · 탄산수소 나트륨 분해(베이킹파우더)
〈 열화학 반응식 작성 규칙 〉
▪① 물질의 상태를 반드시 표기  (s) (l) (g) (aq)
같은 물질이라도 상태가 다르면 엔탈피가 다르기 때문
▪② 온도·압력 조건 표기  기본값 25℃, 1기압
▪③ 계수가 변하면 ΔH도 같은 비율로 변한다
N2(g) + O2(g) → 2NO(g)  ΔH = 180.6 kJ  |  ½N2 + ½O2 → NO  ΔH = 90.3 kJ
▪④ 역반응이면 ΔH의 부호가 반대
H2 + ½O2 → H2O(l)  ΔH = −285.8 kJ  |  H2O(l) → H2 + ½O2  ΔH = +285.8 kJ
〈 상태에 따른 엔탈피 〉
▪같은 물질이면 엔탈피는 고체 < 액체 < 기체
∴고체→액체, 액체→기체는 모두 흡열 (ΔH > 0)
생성물H2O(s)H2O(l)H2O(g)
ΔH (kJ)−291.5−285.8−241.8
엔탈피가장 낮음중간가장 높음
→생성물의 엔탈피가 높을수록 방출하는 열이 적다  |ΔH|는 고체 > 액체 > 기체
〈 열량계와 반응 엔탈피 측정 〉
Q = c × m × Δt
Q 열량(J)  ·  c 비열[J/(g·℃)]  ·  m 용액의 질량(g)  ·  Δt 온도 변화(℃)
▪발열 → 온도 상승 → Q > 0 → 열화학 반응식에서는 ΔH < 0
∴ΔH의 부호는 Q의 부호와 반대
종류구조적합한 반응특징
간이 열량계스타이로폼 컵중화 반응, 고체 용해간단하지만 열 손실이 커 정밀도 낮음
통열량계단열 용기 속 강철 용기연소 반응열 손실 최소화, 정밀 측정
＊함정 주의
발열 반응이니까 ΔH가 양수다 → ✗  발열은 ΔH < 0, 열량 Q와 부호가 반대 중요
계수를 바꿔도 ΔH는 그대로다 → ✗  계수에 비례해서 함께 변한다
물질 상태는 안 써도 된다 → ✗  상태가 다르면 ΔH가 달라지므로 필수
〈 헤스 법칙 〉
▪반응물·생성물의 종류와 상태가 같으면 경로에 관계없이 ΔH 총합이 일정
ΔH전체 = ΔH1 + ΔH2 + ΔH3 + …
→엔탈피는 상태 함수 — 경로가 아니라 처음과 나중 상태에만 의존
직접 측정이 어려운 반응에 활용
C(s) + ½O2 → CO(g) 는 CO2가 함께 생겨 직접 측정이 어렵다
C(s) + O2 → CO2  ΔH1 = −393.5  |  CO + ½O2 → CO2  ΔH3 = −283.0
ΔH2 = ΔH1 − ΔH3 = −393.5 − (−283.0) = −110.5 kJ
푸는 순서  목표식에 맞춰 ① 역반응은 부호 반전 ② 계수는 배수 곱 ③ 더해서 약분
〈 표준 생성 엔탈피 〉
▪물질 1 mol이 가장 안정한 원소 물질로부터 생성될 때의 엔탈피 변화 [kJ/mol]
→표준 상태 = 25℃, 1기압  ·  안정한 원소 단체의 ΔHf° = 0
물질ΔHf°물질ΔHf°물질ΔHf°
C(흑연)0CO(g)−110.5H2O(g)−241.8
O2(g)0CO2(g)−393.5H2O(l)−285.8
H2(g)0CH4(g)−74.6NH3(g)−45.9
C(다이아몬드)는 +1.9 — 흑연이 더 안정하므로 0이 아니다
ΔH = Σ(생성물 ΔHf°) − Σ(반응물 ΔHf°)
메테인 연소  [−393.5 + 2(−285.8)] − [(−74.6) + 0] = −890.5 kJ
〈 결합 에너지 〉
▪기체 상태에서 공유 결합 1 mol을 끊는 데 필요한 에너지 [kJ/mol]
→결합을 끊으면 흡열 (ΔH > 0)  /  결합이 생기면 발열 (ΔH < 0)
결합H−HCl−ClH−ClO=ON 삼중결합C−HO−H
kJ/mol436243432498945413463
ΔH = Σ(반응물 결합 에너지) − Σ(생성물 결합 에너지)
H2 + Cl2 → 2HCl  끊기 436 + 243 = +679  /  형성 −(2 × 432) = −864  →  ΔH = −185 kJ
＊함정 주의
결합 에너지 계산도 생성물 − 반응물이다 → ✗  결합 에너지는 반응물 − 생성물로 순서가 반대 중요
모든 원소의 ΔHf°는 0이다 → ✗  가장 안정한 형태만 0  다이아몬드는 +1.9
헤스 법칙은 경로를 알아야 쓸 수 있다 → ✗  경로와 무관하다는 것이 법칙의 내용
〈 자발적 변화와 엔트로피 〉
▪자발적 변화 — 외부에서 에너지를 주지 않아도 스스로 일어나는 변화
잉크가 물에 퍼짐 · 향수가 공기 중으로 퍼짐 · 드라이아이스가 승화  →  되돌아가지는 않는다
∴공통점은 질서 있는 상태 → 무질서한 상태
▪엔트로피 S — 무질서한 정도  ΔS = S나중 − S처음
상태배열엔트로피
고체규칙적, 위치 고정가장 작음
액체불규칙, 어느 정도 이동중간
기체자유 운동, 매우 무질서가장 큼
▪ΔS 예측은 기체 분자 수 변화로 판단한다
N2O4(g) → 2NO2(g)  1 → 2 mol  ΔS > 0  |  N2 + 3H2 → 2NH3  4 → 2 mol  ΔS < 0
CaCO3(s) → CaO(s) + CO2(g)  고체에서 기체가 생김  ΔS > 0
〈 계·주위와 자발성 판단 〉
▪계 = 반응물과 생성물  ·  주위 = 계를 뺀 나머지  ·  우주 = 계 + 주위
열린계 물질·에너지 모두 교환  |  닫힌계 에너지만 교환  |  고립계 둘 다 교환 ✗
ΔS전체 = ΔS계 + ΔS주위
∴열역학 제2법칙 — ΔS전체 > 0 이면 자발, < 0 이면 비자발
반응ΔH계열 이동주위 온도ΔS주위
발열< 0계 → 주위상승 ↑> 0
흡열> 0주위 → 계하강 ↓< 0

〈 자주 틀리는 5가지 〉
① 발열 반응의 ΔH를 양수로 씀 → 발열은 ΔH < 0
② 결합 에너지 계산을 생성물 − 반응물로 씀 → 반응물 − 생성물
③ 다이아몬드의 ΔHf°를 0이라 씀 → 흑연만 0, 다이아몬드는 +1.9
④ 발열이면 무조건 자발이라고 씀 → ΔS계가 크게 감소하면 비자발일 수 있음
⑤ 흡열인데 자발인 경우는 없다고 씀 → 드라이아이스 승화처럼 ΔS계가 크면 자발
