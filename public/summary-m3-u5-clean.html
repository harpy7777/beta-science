Ⅴ.생식과 유전— 중3 과학핵심정리
〈 생장과 세포 분열 〉
▪생장 = 세포 수의 증가  (세포 크기가 커지는 것 ✗)
1) 강아지가 자라는 것 → 세포가 분열해서 수가 늘어난 것
2) 코끼리와 쥐의 세포 크기는 비슷 → 세포 수의 차이일 뿐
▪세포가 무한정 커지지 않는 까닭
(1) 세포가 커짐 → 부피 증가율 > 표면적 증가율
①즉, 부피에 대한 표면적의 비가 작아짐
②물질을 흡수·배출하기 불리 + 중심까지 거리 ↑
∴어느 정도 크면 분열해서 작아지는 것이 유리
＊우무 실험
2 cm 덩어리(A) vs 1 cm 조각 8개(B)를 수산화나트륨 수용액에
→ A는 겉만, B는 중심까지 붉게 변함
→ 부피는 8로 같지만 표면적 A 24 < B 48
∴ 작을수록 물질 교환에 유리하다
▪세포 주기  — 모세포 → 분열 → 딸세포 2개
간기  — 주기의 약 90%, 생장 + DNA 복제
분열기 — 핵분열 + 세포질 분열
〈 염색체와 유전자 〉
▪염색체 > DNA (유전 물질) > 유전자 (유전 정보)
1) 간기 — 실처럼 풀려 있음  /  분열기 — 응축, 막대 모양
2) 염색체 구성 = DNA + 단백질
▪염색 분체 : 간기에 DNA가 복제되어 생긴 똑같은 두 가닥
→분열할 때 각각의 딸세포로 나뉘어 들어감
▪상동 염색체 : 모양·크기가 같은 한 쌍
→부모에게서 하나씩 물려받음
▪사람의 체세포 염색체 46개 = 23쌍
구분수내용
상염색체22쌍남녀 공통으로 들어 있음
성염색체1쌍성 결정 — 여자 XX / 남자 XY
＊종마다 고유 : 침팬지 48 · 개 78 · 고양이 38 · 완두 14 · 초파리 8
〈 체세포 분열 〉
간기›전기›중기›후기›말기›세포질 분열
① 전기  핵막 사라짐 · 염색체 응축 · 방추사 형성
② 중기  염색체가 세포 중앙에 배열 → 가장 뚜렷!
③ 후기  염색 분체가 분리되어 양극으로 이동
④ 말기  염색체 풀림 · 핵막 다시 생김
▪세포질 분열
동물 — 밖에서 안으로 잘록하게 만입
식물 — 두 핵 사이에 세포판 형성
▪결과 — 딸세포 2개, 염색체 수 변화 없음
→생장 · 상처 재생 · 수명 다한 세포 보충
＊관찰 : 양파 뿌리 끝 생장점 + 아세트산 카민으로 염색
〈 생식세포 분열 = 감수 분열 〉
▪DNA 복제는 딱 1회, 분열은 연속 2회 중요
1) 감수 1분열
①전기 — 상동 염색체가 접합한 2가 염색체 출현
②후기 — 상동 염색체 분리 → 수 절반 (2n → n)
2) 감수 2분열
→복제 없이 시작, 염색 분체 분리 → 수 변화 ✗
＊결과
모세포 1개 → 딸세포 4개, 염색체 수는 모세포의 절반
정자(n) + 난자(n) = 수정란(2n)
∴ 세대를 거듭해도 염색체 수가 일정하게 유지된다
구분체세포 분열생식세포 분열
분열 횟수1회연속 2회
딸세포 수2개4개
2가 염색체형성 ✗형성 ○
염색체 수변화 없음절반으로 감소
〈 사람의 생식과 발생 〉
1) 남자 — 정소(정자 생성) · 부정소 · 수정관(이동 통로)
2) 여자 — 난소 · 수란관(수정 장소!) · 자궁(태아 성장)
▪정자 · 난자 모두 염색체 23개
배란›수정 (수란관)›난할›착상›발생
· 착상 — 수정 약 1주 후 자궁 안쪽 벽에 파고듦 = 임신
· 발생 — 약 266일 (38주) 뒤 출산
▪난할 = 세포가 커지는 시기 없이 빠르게 분열
→세포 수 ↑ · 세포 하나의 크기 ↓
→배아 전체 크기는 수정란과 거의 같음
＊함정 주의
남자의 수정관은 정자가 지나가는 통로일 뿐!
수정이 일어나는 곳은 여자의 수란관 이다.
〈 멘델의 유전 원리 〉
▪기본 용어
(1) 대립 형질 — 둥글다 ↔ 주름지다처럼 대비되는 형질
(2) 순종 자가 수분해도 같은 형질만 / 잡종 다른 순종의 자손
(3) 유전자형 RR·Rr·rr / 표현형 겉으로 드러나는 형질
＊완두를 쓴 까닭
한 세대가 짧다 · 자손이 많다 · 대립 형질이 뚜렷하다
자유롭게 교배할 수 있다 · 기르기 쉽다
▪① 우열의 원리
→순종끼리 교배 → 잡종 1대에 한 형질만 나타남
→나타난 것 = 우성  /  숨은 것 = 열성
▪② 분리의 법칙
→Rr 자가 수분 → RR : Rr : rr = 1 : 2 : 1
∴표현형 둥근 : 주름진 = 3 : 1
▪③ 독립의 법칙
→RrYy 자가 수분 → 잡종 2대 9 : 3 : 3 : 1
＊함정 주의
우성은 "우수한 것"이 아니다!
잡종 1대에 나타났는지로 붙인 이름일 뿐
〈 사람의 유전 연구 〉
▪직접 교배 실험이 불가능한 까닭
① 자유롭게 교배할 수 없음
② 한 세대가 길어 여러 세대 관찰이 어려움
③ 자손 수가 적어 통계 분석이 어려움
∴간접적인 방법으로 연구
(1) 가계도 조사 — 여러 세대의 형질 전달, 우열 관계
(2) 쌍둥이 연구 — 유전 vs 환경의 영향 비교
(3) 통계 조사 — 형질이 나타날 확률 분석
(4) 염색체 · 유전자 분석 — 이상 진단, 직접 비교
〈 사람의 유전 형질 〉
▪상염색체 유전 — 성별과 관계 없음
(1) 혀 말기 : 가능(우성) ↔ 불가능(열성)
(2) 가계도 TIP — 부모에게 없던 형질이 자손에 나오면
→부모의 형질이 우성, 자손의 새 형질이 열성
▪ABO식 혈액형 — A·B·O 3가지 = 복대립 유전
→A, B 는 O 에 우성 / A 와 B 는 공동 우성
표현형A형B형AB형O형
유전자형AA, AOBB, BOABOO
∴표현형 4가지 · 유전자형 6가지
▪성염색체 유전 = 반성유전
→적록 색맹은 X 염색체의 열성 유전자
구분정상보인자색맹
여자XXXX′X′X′
남자XY없음X′Y
→남자는 X가 하나 → X′ 하나만 있어도 색맹
∴남자에게 훨씬 많이 나타남
＊서술형
정상 부모에게서 색맹 아들이 태어났다면?
① 없던 형질이 나타남 → 색맹은 열성
② 아들에게 치우침 → X 염색체 = 반성유전
〈 자주 틀리는 5가지 〉
① 생장을 세포가 커지는 것이라 씀 → 세포 수의 증가
② 감수 분열에서 DNA 복제를 2회라고 씀 → 복제는 1회
③ 수정 장소를 수정관이라 씀 → 수란관
④ 우성을 "우수한 형질"로 해석 → 잡종 1대에 나타난 형질
⑤ 남자 보인자가 있다고 씀 → 남자는 보인자가 없다
