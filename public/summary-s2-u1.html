지질시대의 구분

비율 · 순서 암기
  • 지질시대 지구 탄생 약 46억 년 전부터 현재까지. 넓은 지역에 걸친 급격한 환경 변화를 기준으로 구분한다.
  • 화석 지질시대 생물의 유해나 흔적. 당시 환경을 알려 준다 — 고사리(온난·습한 육상), 산호(수심 얕고 따뜻한 바다).

3

대멸종

  • 짧은 지질학적 기간에 생물종의 상당 비율이 사라지는 사건. 지질시대 동안 총 5번 발생, 수만 ~ 수백만 년에 걸쳐 진행된다.
중생대 말 가설내용증거
소행성 충돌설먼지가 햇빛 차단 → 광합성 불가 → 먹이사슬 붕괴이리듐 고농도, 칙술루브 크레이터
화산 폭발설화산재·가스가 햇빛 차단, 산성비 → 기후 변화인도 데칸 고원 현무암
  • 현재는 소행성 충돌이 방아쇠가 되고 화산 활동·해수면 변화가 복합 작용했다는 견해가 우세하다.
  • 대멸종 후 비워진 생태 공간에서 살아남은 생물이 적응하며 폭발적으로 다양화한다 (공룡 멸종 → 포유류 번성).
시험에 반복되는 함정
  • 진화는 개체가 변하는 것 ✕ — 집단 수준의 변화
  • 환경적 변이로 진화가 일어난다 ✕ — 유전적 변이만
  • 대멸종이 몇 년 사이에 일어났다 ✕ — 수만~수백만 년
  • 종다양성은 종 수만 따진다 ✕ — 고른 분포도 함께

산화·환원의 두 가지 정의

최빈출
구분산소의 이동전자의 이동
산화산소를 얻음전자(e⁻)를 잃음
환원산소를 잃음전자(e⁻)를 얻음
암기 산화 = 산소 얻고 전자 잃고 / 환원 = 산소 잃고 전자 얻고
전자 이동의 예
Cu + 2Ag⁺ → Cu²⁺ + 2Ag — Cu는 전자를 잃어 산화, Ag⁺은 전자를 얻어 환원. 전자는 Cu → Ag⁺ 방향으로 이동한다.
8

철의 제련과 생활 속 산화·환원

철의 제련 (용광로)
① 2C + O₂ → 2CO (탄소가 산화) ② Fe₂O₃ + 3CO → 2Fe + 3CO₂ — CO는 산화, Fe₂O₃는 환원되어 순수한 철을 얻는다.
생활 속 사례내용
철의 부식4Fe + 3O₂ → 2Fe₂O₃ — 철이 산소를 얻어 산화
연소CH₄ + 2O₂ → CO₂ + 2H₂O — 연료의 산화
광합성CO₂가 환원되어 포도당 생성
호흡포도당이 산화되어 에너지 방출
시험에 반복되는 함정
  • 산화와 환원이 따로 일어난다 ✕ — 항상 동시
  • 산화 = 전자를 얻는 것 ✕ — 전자를 잃는 것
  • 중화 반응에서 물 대신 다른 물질이 먼저 ✕ — H⁺+OH⁻→H₂O
  • 흡열 반응이면 주변 온도가 오른다 ✕ — 내려간다
9

산과 염기 · 중화 반응

구분정의(아레니우스)예
산물에 녹아 H⁺을 내놓는 물질HCl → H⁺ + Cl⁻ / H₂SO₄
염기물에 녹아 OH⁻을 내놓는 물질NaOH → Na⁺ + OH⁻ / Ca(OH)₂
중화 반응의 핵심
H⁺ + OH⁻ → H₂O (예: HCl + NaOH → NaCl + H₂O)
남은 이온으로 액성 판단 — H⁺ 남으면 산성, OH⁻ 남으면 염기성, 모두 반응하면 중성
  • 중화열은 실제로 반응한 H⁺·OH⁻의 수에 비례한다 → 완전히 중화되는 지점에서 온도가 가장 높다.
