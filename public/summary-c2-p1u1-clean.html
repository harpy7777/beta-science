Ⅰ.물질의 세 가지 상태— 고2 물질과 에너지핵심정리
〈 기체의 압력과 보일 법칙 〉
▪기체의 압력 — 분자가 단위 면적에 충돌할 때 작용하는 힘  (1기압 = 760 mmHg)
▪보일 법칙 — 온도 일정일 때 압력과 부피는 반비례
PV = 일정  ·  P1V1 = P2V2
→압력 ↑ → 부피 ↓ → 분자 간 거리 가까워짐 → 단위 면적당 충돌 횟수 증가
그래프x축y축모양
P–V압력 P부피 V반비례 곡선 (쌍곡선)
P–1/V1/V압력 P원점 지나는 직선
PV–P압력 PPV수평선 (PV 일정)
잠수부의 공기 방울  수면으로 올라감 → 수압 ↓ → 부피 ↑ → 방울이 커진다
〈 샤를 법칙과 절대 온도 〉
▪절대 온도 T(K) = t(℃) + 273  — 기체 부피가 0이 되는 −273℃가 기준
0℃ = 273 K  /  27℃ = 300 K  /  −73℃ = 200 K
▪샤를 법칙 — 압력 일정일 때 부피는 절대 온도에 비례
V / T = 일정  ·  V1 / T1 = V2 / T2
→온도 ↑ → 분자 운동 활발 → 벽에 충돌하는 힘 ↑ → 부피 팽창으로 압력 유지
섭씨로는  1℃ 오를 때마다 0℃ 부피의 1/273씩 증가
가로축그래프 모양해석
섭씨온도 (℃)직선 (원점 통과 ✗)−273℃에서 부피 = 0으로 외삽
절대 온도 (K)직선 (원점 통과 ○)V ∝ T 정비례가 명확
〈 아보가드로 법칙 〉
▪온도·압력이 같으면 기체의 종류와 관계없이 같은 부피 속에 같은 수의 분자
V ∝ n  ·  0℃, 1기압에서 기체 1 mol = 22.4 L
→H2 1 mol = 22.4 L, O2 1 mol = 22.4 L  — 분자의 크기·질량과 무관
∴분자 사이 거리가 매우 멀어 분자 자체의 크기는 무시할 수 있기 때문
〈 이상 기체 방정식 〉
법칙고정 조건관계
보일T, n 일정V ∝ 1/P
샤를P, n 일정V ∝ T
아보가드로T, P 일정V ∝ n
통합—V ∝ nT / P
PV = nRT  ·  R ≒ 0.082 기압·L/(mol·K)
R 구하기  R = PV/nT = (1 × 22.4) ÷ (1 × 273) ≒ 0.082
▪분자량 구하기 — n = w/M 을 대입
M = wRT / PV
→질량 w(g) · 온도 T(K) · 압력 P(기압) · 부피 V(L)만 측정하면 분자량이 나온다
이상 기체란
분자의 크기를 무시할 수 있고, 분자 간 인력·반발력이 없는 가상의 기체
실제 기체는 압력이 낮고 온도가 높을수록 이상 기체에 가까워진다
＊함정 주의
샤를 법칙에 섭씨온도를 그대로 대입 → ✗  반드시 절대 온도 K로 바꿔서 계산 중요
22.4 L는 모든 조건에서 1 mol의 부피다 → ✗  0℃, 1기압일 때만 성립
분자량이 크면 같은 부피에 분자 수가 적다 → ✗  온도·압력이 같으면 분자 수는 같다
〈 돌턴의 부분 압력 법칙 〉
▪분압 — 섞인 기체 중 각 성분이 단독으로 나타내는 압력
Pt = PA + PB + PC + …
→근거  온도·부피가 같으면 압력은 mol 수에만 비례하고 기체 종류와는 무관
PA = nART/V  ·  PB = nBRT/V  →  Pt = (nA + nB)RT/V
〈 몰분율과 분압 〉
▪몰분율 X = 성분 기체의 mol ÷ 전체 mol  — 모든 성분의 몰분율 합 = 1
PA = Pt × XA
∴각 성분의 분압은 몰분율에 비례한다
부피가 바뀌면  먼저 보일 법칙으로 각 기체의 분압을 새 부피에 맞춰 구한 뒤 합한다

〈 분자 간 힘의 종류 〉
▪분자 간 힘이 클수록 상태 변화에 더 많은 에너지 필요 → 녹는점·끓는점이 높다
∴끓는점 차이로 분자 간 힘의 크기를 비교할 수 있다
▪① 쌍극자·쌍극자 힘 — 극성 분자 사이
전기음성도 차 → 전자 분포 불균일 → 부분 전하 발생  예) H(δ+)—Cl(δ−)
→분자량이 비슷하면 쌍극자 모멘트가 클수록 끓는점이 높다
▪② 분산력 — 모든 분자 사이 (무극성 포함)
전자가 순간적으로 치우침 → 순간 쌍극자 → 이웃에 쌍극자 유발 → 인력
→분자량이 클수록 전자가 많아 편극이 잘 일어나 분산력이 커진다

▪③ 수소 결합 — 가장 강한 분자 간 힘
조건  O · N · F에 결합한 H와 이웃 분자의 O · N · F 사이  예) H2O, NH3, HF
→전기음성도  F(4.0) > O(3.4) > N(3.0) > C(2.6) > H(2.2)
종류작용 분자세기비고

＊함정 주의
분자량이 크면 항상 끓는점이 높다 → ✗  H2O(18, 100℃) > H2S(34, −59.6℃) — 수소 결합 때문 중요
분산력은 무극성 분자에만 작용한다 → ✗  모든 분자에 작용한다
수소가 있으면 수소 결합을 한다 → ✗  PH3는 P의 전기음성도가 작아 수소 결합 없음
〈 동적 평형과 증기 압력 〉
▪밀폐 용기에서 증발 속도 = 응축 속도가 되면 동적 평형
→겉보기엔 변화가 없지만 증발과 응축은 계속 일어난다
▪증기 압력 — 동적 평형에서 증기가 나타내는 압력
조건증기 압력이유
온도 ↑증가분자 운동 활발 → 증발 잘 일어남
분자 간 힘 강함작음증발하기 어렵다 → 끓는점 높음
분자 간 힘 약함큼증발 잘 일어남 → 끓는점 낮음
증기 압력  다이에틸 에터 > 에탄올 > 물  |  분자 간 힘  물 > 에탄올 > 다이에틸 에터
〈 끓는점과 외부 압력 〉
▪끓는점 = 액체의 증기 압력이 외부 압력과 같아지는 온도
기준 끓는점  외부 압력이 1기압일 때의 끓는점
→외부 압력 ↓ → 끓는점 낮아짐  /  외부 압력 ↑ → 끓는점 높아짐
높은 산  압력 ↓ → 100℃ 미만에서 끓음 → 밥이 설익음  |  압력밥솥  압력 ↑ → 빨리 익음

〈 결정성 고체와 비결정성 고체 〉
구분입자 배열녹는점예
결정성 고체규칙적일정석영 · NaCl · 철 · 얼음

〈 자주 틀리는 5가지 〉
① 이상 기체 계산에 섭씨온도를 씀 → 반드시 절대 온도 K
② 분자량이 크면 끓는점이 높다고 씀 → 수소 결합 여부를 먼저 확인
③ 이온 결정이 고체에서 전기가 통한다고 씀 → 고체는 통하지 않음, 액체·수용액만
④ 공유 결정은 모두 부도체라고 씀 → 흑연은 예외로 전기가 통함
⑤ 유리를 결정성 고체라고 씀 → 배열이 불규칙한 비결정성 고체
