Ⅵ.동물과 에너지— 중2 과학핵심정리
〈 영양소 〉
▪3대 영양소 = 탄수화물 · 단백질 · 지방 → 에너지원으로 쓰인다
▪부영양소 = 바이타민 · 무기염류 · 물 → 에너지원으로 쓰이지 않는다
영양소기능
탄수화물주로 에너지원
단백질몸 구성 · 생명활동 조절 · 에너지원
지방몸 구성 · 에너지원 · 체온 유지
바이타민적은 양으로 생명활동 조절
무기염류뼈 · 이 구성 · 생명활동 조절
물몸의 구성 성분 중 가장 많음 · 물질 운반
검출 영양소용액색깔 변화
당분(포도당)베네딕트 (가열)황적색
녹말아이오딘 용액청람색
단백질뷰렛 용액보라색
지방수단 Ⅲ선홍색
＊함정 주의
바이타민·무기염류도 에너지원이다 → ✗  조절 기능만 중요
베네딕트 반응은 반드시 가열해야 색이 변한다
〈 소화 〉
▪소화 = 큰 영양소를 작게 분해해 흡수될 수 있게 하는 과정
▪소화관  입 → 식도 → 위 → 작은창자 → 큰창자 → 항문
기관소화효소작용
입아밀레이스녹말 → 엿당
위펩신 (+ 염산)단백질 분해 시작
작은창자아밀레이스 · 트립신 · 라이페이스녹말 · 단백질 · 지방 분해
쓸개즙소화효소 없음지방 소화를 도움
영양소최종 분해 산물흡수 통로
녹말포도당융털의 모세혈관
단백질아미노산융털의 모세혈관
지방지방산 + 모노글리세라이드융털의 암죽관
∴작은창자의 주름과 융털 → 표면적이 넓어 흡수에 유리
＊함정 주의
쓸개즙에도 소화효소가 있다 → ✗  효소 없이 지방을 잘게 쪼개 줄 뿐
큰창자에서는 소화가 아니라 주로 물을 흡수한다
〈 순환 〉
▪심방 = 혈액을 받는 곳(정맥 연결) / 심실 = 혈액을 내보내는 곳(동맥 연결)
→심실의 근육이 심방보다 두껍다 · 판막은 혈액의 역류를 방지
혈관특징
동맥심장에서 나가는 혈액 · 벽이 두껍고 탄력 강함
모세혈관가장 가늘다 · 조직세포와 물질 교환
정맥심장으로 들어가는 혈액 · 벽이 얇고 판막 있음
혈액 성분기능
혈장물질 운반
적혈구산소 운반 (헤모글로빈)
백혈구세균을 잡아먹는 방어
혈소판혈액 응고
▪온몸 순환  좌심실 → 대동맥 → 온몸 모세혈관 → 대정맥 → 우심방
▪폐 순환  우심실 → 폐동맥 → 허파 모세혈관 → 폐정맥 → 좌심방
〈 호흡 〉
▪호흡계  코 → 숨관 → 숨관가지 → 허파 · 허파는 허파꽈리로 표면적 확대
∴허파는 근육이 없어 스스로 움직이지 못한다
구분갈비뼈가로막부피압력공기
들숨올라감내려감커짐낮아짐밖 → 허파
날숨내려감올라감작아짐높아짐허파 → 밖
→기체 교환은 농도 차에 의한 확산 · 산소는 허파꽈리 → 혈액 → 조직세포
＊함정 주의
가로막이 들숨 때 올라간다 → ✗  들숨은 갈비뼈 ↑, 가로막 ↓ 중요
〈 배설 〉
▪노폐물  이산화 탄소 → 날숨 / 물 → 날숨·오줌·땀 / 암모니아 → 간에서 요소로
▪배설계  콩팥 → 오줌관 → 방광 → 요도 · 기본 단위는 콩팥단위(네프론)
과정이동물질
여과토리 → 보먼주머니작은 물질 (포도당 · 요소 · 물)
재흡수세뇨관 → 모세혈관포도당 · 아미노산 전부 · 물 대부분
분비모세혈관 → 세뇨관남아 있던 노폐물
＊함정 주의
정상 오줌에 포도당이 없는 이유 = 전부 재흡수되기 때문
단백질·혈구도 여과된다 → ✗  크기가 커서 여과되지 않는다
〈 기관계의 통합적 작용 〉
포도당 + 산소 → 이산화 탄소 + 물 + 에너지
기관계역할
소화계영양소 흡수
호흡계산소 흡수 · 이산화 탄소 배출
순환계영양소 · 산소 · 노폐물 운반
배설계요소 등 노폐물 배출
∴네 기관계가 서로 연결되어 세포호흡을 가능하게 한다
〈 자주 틀리는 5가지 〉
① 바이타민을 에너지원이라 씀 → 조절 기능
② 쓸개즙에 소화효소가 있다고 씀 → 효소 없음
③ 지방 흡수를 모세혈관이라 씀 → 암죽관
④ 들숨 때 가로막이 올라간다고 씀 → 내려간다
⑤ 온몸 순환 출발을 우심실이라 씀 → 좌심실
