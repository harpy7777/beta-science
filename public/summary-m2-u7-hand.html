Ⅶ.전기와 자기— 중2 과학핵심정리
〈 마찰 전기와 전기력 〉
▪원자는 보통 전기적으로 중성 · 마찰하면 전자만 이동한다
물체전자띠는 전기
전자를 잃은 물체감소(+)전기
전자를 얻은 물체증가(−)전기
▪대전 = 물체가 전기를 띠는 현상 · 대전체 = 대전된 물체
▪전기력  다른 종류 → 끌어당김(인력) / 같은 종류 → 밀어냄(척력)
＊함정 주의
마찰하면 원자핵(양성자)도 이동한다 → ✗  이동은 전자뿐 중요
〈 정전기 유도 〉
▪대전되지 않은 금속에 대전체를 가까이 하면 양 끝이 전기를 띤다
∴금속 속 자유전자가 이동하기 때문
위치띠는 전기
대전체와 가까운 쪽대전체와 다른 종류
대전체와 먼 쪽대전체와 같은 종류
→(−)대전체 → 전자가 밀려 먼 쪽으로 → 가까운 쪽 (+), 먼 쪽 (−)
〈 전류와 전압 〉
구분정의단위
전류전하(전자)의 흐름A (암페어)
전압전류를 흐르게 하는 능력V (볼트)
저항전류의 흐름을 방해하는 정도Ω (옴)
▪전류의 방향 = (+)극 → (−)극 · 전자의 이동 = (−)극 → (+)극
→물의 흐름 비유  펌프 = 전지 · 높이 차 = 전압 · 물의 흐름 = 전류
＊함정 주의
전류와 전자의 이동 방향이 같다 → ✗  서로 반대 중요
〈 옴의 법칙 〉
전압(V) = 전류(I) × 저항(R)
→전류 I = V ÷ R  ·  예) 10 V, 5 Ω → 2 A
▪전류는 전압에 비례 · 저항에 반비례
〈 저항의 연결 〉
구분직렬연결병렬연결
전체 저항커진다작아진다
전체 전류작아진다커진다
전구 밝기한 개보다 어둡다한 개일 때와 같다
하나가 끊기면나머지도 꺼짐나머지는 켜짐
→멀티탭 콘센트는 병렬연결 → 하나를 꺼도 나머지는 그대로
〈 전기 에너지의 전환 〉
전환 형태전기 기구
열에너지전기난로 · 전기밥솥 · 전기 오븐
빛에너지전구 · 형광등 · LED
운동 에너지선풍기 · 세탁기 · 전동기
소리 에너지스피커 · 이어폰
▪소비 전력 = 1초 동안 사용하는 전기 에너지의 양 · 단위 W(와트)
〈 전류가 만드는 자기장 〉
▪자기력 = 자석 사이에 작용하는 힘 / 자기장 = 자기력이 작용하는 공간
∴자기장의 방향 = 나침반 바늘 N극이 가리키는 방향
▪전류가 흐르는 코일 주위에도 자기장이 생긴다
전류의 방향이 바뀌면 → 자기장 방향도 반대
전류가 셀수록 → 자기장도 세진다
▪전자석 = 전류가 흐를 때만 자석이 되는 장치 · 끊으면 자기력 사라짐
〈 코일이 받는 힘과 전동기 〉
▪오른손  네 손가락 = 자기장, 엄지 = 전류 → 손바닥 방향 = 힘
▪힘의 방향이 반대가 되는 경우
① 전류의 방향을 바꾼다
② 자기장(자석의 극)의 방향을 바꾼다
→둘 다 동시에 바꾸면 힘의 방향은 그대로이다
▪전동기  코일 좌우의 전류 방향이 반대 → 받는 힘도 반대 → 회전
〈 자주 틀리는 5가지 〉
① 마찰 때 양성자가 이동한다고 씀 → 전자만 이동
② 전류와 전자의 방향을 같다고 씀 → 반대
③ 정전기 유도에서 가까운 쪽을 같은 전기라 씀 → 다른 전기
④ 병렬연결에서 전체 저항이 커진다고 씀 → 작아진다
⑤ 전류·자기장을 둘 다 바꾸면 힘이 반대라고 씀 → 그대로
