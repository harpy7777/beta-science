Ⅰ.산 염기 평형— 고2 화학 반응의 세계핵심정리
〈 아레니우스 정의와 그 한계 〉
▪산 = 물에 녹아 H+를 내놓음  /  염기 = 물에 녹아 OH−를 내놓음
▪한계 세 가지
① 수용액에서만 적용  HCl(g) + NH3(g) → NH4Cl(s)는 설명 불가
② NH3는 OH−가 없는데 염기성을 띤다  물과 반응해 OH−를 만들기 때문
③ H+는 단독으로 못 있고 H3O+(하이드로늄)로 존재한다
〈 브뢴스테드·라우리 정의 〉
▪산 = 양성자 H+를 주는 물질  ·  염기 = H+를 받는 물질
∴수용액이 아니어도 적용되고 NH3의 염기성도 설명된다
반응물 1역할반응물 2역할생성물
HCl산H2O염기H3O+ + Cl−
NH3염기H2O산NH4+ + OH−
CH3COOH산H2O염기CH3COO− + H3O+
▪양쪽성 물질 — 조건에 따라 산도 되고 염기도 되는 물질  H2O · HCO3−
HCO3− + H2O ↔ H2CO3 + OH−  염기  |  HCO3− + NH3 ↔ CO32− + NH4+  산
〈 짝산 · 짝염기 〉
▪짝산 = 염기 + H+  ·  짝염기 = 산 − H+  →  H+ 하나 차이
이온화 평형짝산·짝염기 쌍 ①짝산·짝염기 쌍 ②
HF + H2O ↔ F− + H3O+HF(산) ↔ F−H2O(염기) ↔ H3O+
NH3 + H2O ↔ NH4+ + OH−NH3(염기) ↔ NH4+H2O(산) ↔ OH−
H2O + H2O ↔ H3O+ + OH−H2O는 H3O+의 짝염기이자 OH−의 짝산
→역반응에서는 역할이 바뀐다  F−(염기) + H3O+(산) → HF + H2O
＊함정 주의
H2O는 항상 염기다 → ✗  HCl과는 염기, NH3와는 산으로 작용 중요
짝산·짝염기는 이온끼리의 쌍이다 → ✗  H+ 하나 차이면 분자든 이온이든 쌍이다
아레니우스 정의로 NH3를 설명할 수 있다 → ✗  OH−가 없어 설명 불가
〈 산 염기의 세기 〉
구분이온화 정도예
강산거의 100% 이온화HCl · H2SO4 · HNO3 · HBr · HI
약산일부만 이온화CH3COOH · HF · HCN · H2CO3
강염기거의 100% 이온화NaOH · KOH · Ca(OH)2
약염기일부만 이온화NH3 · CH3NH2
같은 0.1 M 비교  HCl pH ≈ 1  |  CH3COOH pH ≈ 3  →  H3O+ 생성량이 다르기 때문
〈 이온화 상수 Ka · Kb 〉
HA + H2O ↔ A− + H3O+  ·  B + H2O ↔ BH+ + OH−
Ka = [A−][H3O+] / [HA]  ·  Kb = [BH+][OH−] / [B]
→물의 농도는 일정하므로 평형 상수에 [H2O]를 곱해 Ka로 묶는다
→Ka 클수록 강산  /  Kb 클수록 강염기
산Ka (25℃)염기Kb (25℃)
HF6.8 × 10−4CH3NH2 메틸아민4.6 × 10−4
CH3COOH 아세트산1.8 × 10−5NH3 암모니아1.8 × 10−5
HCN6.2 × 10−10C6H5NH2 아닐린7.4 × 10−10
HCl 강산약 107NaOH 강염기약 1020
강산·강염기는 K 값이 매우 커서 사실상 완전 이온화로 취급한다
▪이온화 상수의 성질
① 온도가 일정하면 농도와 무관하게 일정  ② 온도가 바뀌면 값도 바뀐다
③ 짝산·짝염기 사이에  Ka × Kb = Kw
참고  물의 값 1.0 × 10−14은 Ka가 아니라 Kw(물의 이온화 상수)다
〈 약산·약염기 수용액의 pH 계산 〉
1단계 이온화 평형식과 평형 농도표(ICE) 작성  처음 / 변화 / 평형
2단계 Ka 식에 대입 — 약산이므로 x가 아주 작아 (C − x) ≈ C로 근사
3단계 pH = −log[H3O+]
약염기는 pOH를 먼저 구하고  pH = 14 − pOH  로 넘어간다
〈 중화 적정 〉
▪농도를 모르는 산·염기의 농도를 구하는 방법  H+ + OH− → H2O  (1 : 1)
표준 용액 농도를 정확히 아는 용액  |  중화점 H+ mol = OH− mol (이론)
종말점 지시약 색이 변하는 지점 (실험)  →  중화점으로 간주
지시약산성변색 pH염기성적용
메틸 오렌지빨강3.1 ~ 4.4노랑강산 + 강염기
메틸 레드빨강4.4 ~ 6.2노랑강산 + 강염기
BTB노랑6.0 ~ 7.6파랑강산 + 강염기
페놀프탈레인무색8.3 ~ 10.0분홍강산·약산 + 강염기
→약산 적정은 중화점이 pH 8~9라 메틸 레드는 너무 일찍 변해 못 쓴다
〈 중화 적정 곡선 — 강산 vs 약산 〉
항목강산 + 강염기약산 + 강염기
초기 pH낮음상대적으로 높음
중화점 전급격히 증가완만하게 증가
중화점 pH7.0 (NaCl, 가수 분해 없음)7.0 초과 (CH3COONa 가수 분해)
중화점 근처둘 다 pH가 급격히 변한다
중화점 이후강염기가 지배 — 거의 같은 모양
지시약메틸 레드 · BTB · 페놀프탈레인페놀프탈레인만
반중화점 — 약산 적정에서만 나오는 지점
넣어 준 NaOH가 처음 HA의 절반인 지점 → [HA] ≈ [A−]
Ka = [A−][H3O+] / [HA] ≈ [H3O+]  →  pKa = pH
이 지점의 pH를 재면 약산의 Ka를 구할 수 있다
〈 Ka × Kb = Kw 〉
HA + H2O ↔ A− + H3O+  ·  A− + H2O ↔ HA + OH−
Ka × Kb = [H3O+][OH−] = Kw = 1 × 10−14 (25℃)
∴산이 강할수록 그 짝염기는 약하다 — 반비례 관계
CH3COOH Ka = 1.8 × 10−5 → CH3COO−의 Kb = 5.6 × 10−10
HCN Ka = 6.2 × 10−10 → CN−의 Kb = 1.6 × 10−5  CH3COO−보다 강한 염기
참고  Kw = [H3O+][OH−] = 10−14  →  pH + pOH = 14
〈 염의 가수 분해 〉
▪염의 이온이 물과 반응해 H3O+나 OH−를 만드는 반응
∴액성은 그 염을 만든 산과 염기의 세기로 결정된다
생성 조합염의 예가수 분해액성
강산 + 강염기NaCl · KNO3 · CaCl2✗중성 (pH = 7)
약산 + 강염기CH3COONa · NaCN · NaF음이온이 가수 분해염기성 (pH > 7)
강산 + 약염기NH4Cl · CH3NH3Cl양이온이 가수 분해산성 (pH < 7)
약산 + 약염기CH3COONH4양·음이온 모두Ka·Kb 비교로 결정
CH3COO− + H2O ↔ CH3COOH + OH−  →  염기성
NH4+ + H2O ↔ NH3 + H3O+  →  산성
→판단 순서  염을 산과 염기로 되돌린 뒤 어느 쪽이 약한지 본다 — 약한 쪽의 성질이 나타난다
＊함정 주의
Ka가 크면 약산이다 → ✗  Ka가 클수록 강산 중요
NaCN 수용액은 산성이다 → ✗  약산 HCN의 염이라 CN−가 가수 분해 → 염기성
모든 염 수용액은 중성이다 → ✗  강산+강염기 염만 중성
〈 완충 용액 〉
▪소량의 산·염기를 넣어도 pH가 거의 변하지 않는 용액
조성  ① 약산 + 그 짝염기  CH3COOH + CH3COONa  |  ② 약염기 + 그 짝산  NH3 + NH4Cl
→산을 넣으면  CH3COO− + H+ → CH3COOH  짝염기가 H+를 흡수
→염기를 넣으면  CH3COOH + OH− → CH3COO− + H2O  약산이 OH−를 중화
완충 쌍조성pH 범위
CH3COOH / CH3COO−CH3COOH + CH3COONa약 3.7 ~ 5.7
NH4+ / NH3NH3 + NH4Cl약 8.3 ~ 10.3
H2CO3 / HCO3−혈액 속에 존재혈액 pH ≈ 7.4
완충 용액이 아닌 것
① 강산 + 그 염  HCl + NaCl — 이미 완전 이온화되어 짝이 공존하지 않는다
② 약산 + 강염기를 1 : 1로 혼합 — 완전 중화되어 염만 남는다
→ 약산을 절반만 중화시키면(1 : 0.5) 약산과 짝염기가 공존해 완충 용액이 된다
〈 생체 내 완충 작용 〉
CO2 + H2O ↔ H2CO3  ·  H2CO3 + H2O ↔ HCO3− + H3O+
상황반응결과
H3O+ 증가 (운동 후 젖산)HCO3− + H3O+ → H2CO3 + H2OH3O+ 소모 → pH 유지
OH− 증가H2CO3 + OH− → HCO3− + H2OOH− 소모 → pH 유지
과호흡CO2 감소 → H3O+ 감소pH 상승 (알칼리증)
얕은 호흡CO2 증가pH 하강 (산증)
해양 산성화  바다가 대기 CO2의 약 25%를 흡수해 완충하지만, 급증하면 능력을 넘어선다
→CO32−가 줄어 산호·조개가 CaCO3 껍데기를 못 만든다
〈 핵심 공식 모음 〉
공식의미쓰는 곳
Ka = [A−][H3O+] / [HA]산의 이온화 상수약산 pH 계산
Kb = [BH+][OH−] / [B]염기의 이온화 상수약염기 pH 계산
Ka × Kb = Kw짝산·짝염기 관계가수 분해 판단
Kw = 10−14 (25℃)물의 이온화 상수pH + pOH = 14
pH = −log[H3O+]pH 정의모든 수용액
〈 자주 틀리는 5가지 〉
① Ka가 크면 약산이라고 씀 → 클수록 강산
② 약산 적정 중화점을 pH 7이라고 씀 → 가수 분해로 7보다 크다
③ 약산 적정에 메틸 레드를 씀 → 페놀프탈레인만 가능
④ NaCN을 산성이라고 씀 → 약산의 염이라 염기성
⑤ 약산 + 강염기 1 : 1 혼합을 완충 용액이라 씀 → 완전 중화라 완충 아님
