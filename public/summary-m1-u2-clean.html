Ⅱ.생물의 구성과 다양성— 중1 과학핵심정리
〈 세포의 구조와 기능 〉
▪세포 = 생명활동이 일어나는 기본 단위 · 몸을 이루는 가장 작은 단위
→영국의 훅이 코르크를 관찰하다 발견하고 이름 붙였다
세포소기관기능
핵가장 크고 둥글다 · 생명활동 조절
세포막얇은 막 · 물질의 출입 조절
세포질핵과 세포막 사이 · 여러 생명활동
마이토콘드리아에너지를 만든다
세포벽식물만 · 두껍고 단단 · 보호와 모양 유지
엽록체식물만 · 초록색 · 광합성이 일어남
∴공통 = 핵 · 세포막 · 세포질 · 마이토콘드리아 / 식물만 = 세포벽 · 엽록체
＊함정 주의
동물 세포에도 세포벽이 있다 → ✗  세포벽·엽록체는 식물만 중요
〈 생물의 유기적 구성 〉
▪동물  세포 → 조직 → 기관 → 기관계 → 개체
▪식물  세포 → 조직 → 조직계 → 기관 → 개체
단계동물식물
3단계기관계 (동물만)조직계 (식물만)
예소화계 · 순환계 · 호흡계관다발 · 표피 · 기본조직계
→위치도 다르다 — 동물은 기관 다음, 식물은 기관 앞
＊함정 주의
식물에도 기관계가 있다 → ✗  식물은 조직계 중요
기관계는 기관 뒤, 조직계는 기관 앞에 온다
〈 변이와 생물다양성 〉
▪변이 = 같은 종류의 생물 사이에서 나타나는 서로 다른 특징
→환경과 비슷한 개체가 살아남아 자손에게 특성을 전달 → 오랜 시간 뒤 다른 종이 됨
▪생물다양성 = 변이의 다양성 + 종류의 다양성 + 생태계의 다양성
＊함정 주의
개체의 크기도 생물다양성 요인이다 → ✗  관계 없다
〈 생물의 분류 〉
▪분류 기준은 생물 고유의 특징이어야 한다
○ 척추 유무 · 번식 방법 · 광합성 여부 · 핵의 유무
✗ 약으로 쓸 수 있는지 · 집에서 키울 수 있는지 → 사람의 편의
▪종 = 자연 상태에서 번식 능력이 있는 자손을 낳는 무리
→말 + 당나귀 → 노새는 번식 불가 → 둘은 다른 종
종›속›과›목›강›문›계
◀ 작은 단계   |   큰 단계 ▶
〈 생물의 5계 〉
계핵세포벽세포 수광합성예
원핵생물계없음있음단세포대부분 ✗대장균 · 젖산균 · 남세균
원생생물계있음있기도단세포 등있기도아메바 · 유글레나 · 김
식물계있음있음다세포○소나무 · 고사리 · 민들레
균계있음있음다세포✗버섯 · 곰팡이
동물계있음없음다세포✗호랑이 · 잠자리 · 잉어
→균계는 균사를 가지고 죽은 생물을 분해해 양분을 얻는다
＊함정 주의
핵이 없는 계는 원핵생물계뿐
세포벽이 없는 계는 동물계뿐 중요
〈 생물다양성 보전 〉
▪생태계는 그물망처럼 연결 → 한 종이 사라지면 다른 생물도 영향
∴생태계평형 = 생물의 종류와 수가 크게 변하지 않는 안정된 상태
감소 원인사례
서식지 파괴갯벌 매립 · 도로 건설
불법 · 과도한 포획나도풍란 채취
외래종 유입가시박 · 배스
기후 변화해수면 상승으로 서식지 소멸
→보전 노력  생태통로 · 포획 단속 · 외래종 관리 · 탄소 감축
＊함정 주의
모든 외래종은 해롭다 → ✗  토끼풀 · 서양민들레처럼 잘 정착한 것도 있다
〈 자주 틀리는 5가지 〉
① 동물 세포에 세포벽이 있다고 씀 → 식물만
② 식물에 기관계가 있다고 씀 → 조직계
③ 원핵생물계에 핵이 있다고 씀 → 없다
④ 동물계에 세포벽이 있다고 씀 → 없다
⑤ 노새를 같은 종의 근거로 씀 → 번식 불가라 다른 종
