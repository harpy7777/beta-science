Ⅳ.물질의 상태 변화— 중1 과학핵심정리
〈 증발과 확산 〉
▪증발 = 액체 표면에서 입자가 떨어져 나와 기체로 변하는 현상
▪확산 = 입자가 스스로 운동하여 멀리 퍼져 나가는 현상
∴둘 다 입자가 스스로 운동한다는 증거
＊함정 주의
확산도 상태 변화다 → ✗  확산은 퍼지는 것일 뿐 중요
증발만 액체 → 기체 상태 변화
〈 물질의 세 가지 상태 〉
구분고체액체기체
입자 거리매우 가깝다비교적 가깝다매우 멀다
입자 배열규칙적불규칙매우 불규칙
입자 운동제자리 진동자유롭게 이동가장 활발
모양일정변한다변한다
부피일정일정변한다
〈 6가지 상태 변화 〉
이름방향예
융해고체 → 액체얼음이 녹음 · 버터가 녹음
응고액체 → 고체물이 얾 · 쇳물이 굳음
기화액체 → 기체물이 수증기로
액화기체 → 액체이슬 · 안경에 서린 김
승화 ①고체 → 기체드라이아이스가 사라짐
승화 ②기체 → 고체나뭇잎의 서리
고체›액체›기체
융해 · 기화 ▶   |   ◀ 응고 · 액화   |   승화 = 고체 ⇄ 기체
▪변하지 않는 것  질량 · 입자의 개수 · 종류 · 크기 · 성질
▪변하는 것  입자 사이의 거리 · 부피
＊함정 주의
상태가 변하면 질량도 변한다 → ✗  질량은 그대로 중요
예외 — 물이 얼 때는 부피가 커진다
〈 열에너지를 흡수하는 상태 변화 〉
▪융해 · 기화 · 승화(고→기) → 열에너지 흡수
∴주위의 온도가 낮아진다
▪상태 변화가 일어나는 동안 온도는 일정하다
→흡수한 열이 온도를 올리는 대신 입자 배열을 불규칙하게 만드는 데 쓰이기 때문
→예  물놀이 후 추운 이유 = 몸의 물이 기화하며 열을 빼앗음
〈 열에너지를 방출하는 상태 변화 〉
▪응고 · 액화 · 승화(기→고) → 열에너지 방출
∴주위의 온도가 높아진다 · 입자 배열은 규칙적으로
→예  추울 때 과일나무에 물을 뿌림 = 응고하며 열을 방출해 얼지 않게
＊함정 주의
상태 변화 중에도 온도가 계속 오른다 → ✗  일정하다 중요
〈 생활 속 이용 〉
구분상태 변화열에너지주위 온도
흡열융해 · 기화 · 승화(고→기)흡수낮아진다
발열응고 · 액화 · 승화(기→고)방출높아진다
▪에어컨  실내기에서 냉매가 기화(흡수) · 실외기에서 액화(방출)
▪드라이아이스  승화하며 열 흡수 → 젖지 않게 냉동 보관
→항아리 냉장고 · 여름철 물 뿌리기 = 기화 / 찜질 팩 = 응고
〈 자주 틀리는 5가지 〉
① 확산을 상태 변화라고 씀 → 증발만 상태 변화
② 상태 변화로 질량이 변한다고 씀 → 일정
③ 상태 변화 중 온도가 오른다고 씀 → 일정
④ 승화를 한 방향만 씀 → 양쪽 모두 승화
⑤ 에어컨 실내기를 액화라고 씀 → 기화(흡열)
